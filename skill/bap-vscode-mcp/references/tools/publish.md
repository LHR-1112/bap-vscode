# publish

发布插件（全量）到所有用户。

## 参数

| 参数 | 类型 | 说明 | 必需 |
|------|------|------|------|
| `ignoreErrors` | boolean | 编译有错是否仍发布 | 否（缺省 false：有错则失败） |

## 示例

```json
{ "name": "publish", "arguments": {} }
```

## 返回

成功/失败；失败时返回错误信息（发布/全量导出为长耗时，已放宽超时，等待更久）。

## 注意

- `publish` 是不可逆、面向所有用户的操作，必须先让用户明确确认。
- 默认 `ignoreErrors=false`：若编译报错会失败并返回原因，不会静默发布。
