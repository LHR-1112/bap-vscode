# commit

提交本地变更到云端。

## 参数

| 参数 | 类型 | 说明 | 必需 |
|------|------|------|------|
| `comment` | string | 提交说明 | 否（缺省空） |

## 示例

```json
{ "name": "commit", "arguments": { "comment": "修复登录问题" } }
```

## 返回

提交结果的摘要（提交的文件 / 包体信息）。

## 工作流

1. 先 `refresh` 确认变更符合预期。
2. 调用 `commit` 提交全部非 NORMAL 变更。

## 注意

- `commit` 提交的是本地相对云端的改动（新增/修改/删除），云端是基线。
- 提交前应让用户确认变更范围与说明。
